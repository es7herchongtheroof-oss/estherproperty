# Esther Chong Property Website

One-page real estate agent website for Esther Chong Fei Min.

## Deploy

This is a static site. Deploy the repository root on Vercel with no build command and `.` as the output directory. Vercel can deploy updates automatically from the `main` branch after the GitHub repository is connected.

## Files

- `index.html` — page markup, styles, metadata, and form behavior
- `esther-chong.jpg` — profile photo used in the hero
